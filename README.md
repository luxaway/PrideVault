# PrideVault

Wallet MultiversX pour **Heart of ROAR** / **ROARHighSpeX**.

Swap contre ROAR, farm Heart (OOX), stake ROAR (xExchange), chat live, board, et connexion **xPortal**.

## Stack

TanStack Start · React 19 · Tailwind v4 · Neon/PGLite · MultiversX (xPortal / WalletConnect)

## Lancer le projet

```bash
npm install
npm run dev
```

Build :

```bash
npm run typecheck
npm run build
```

## Swap

- **EGLD → ROAR** : prix du pool xExchange (instantané)
- **Tous les autres tokens** : agrégateur JEXchange, **dans l’app** (pas de redirection)
- Garde **0.01 EGLD** pour les frais de tx

## Chat / X

Identité on-chain (herotag, nick, X vérifié). Les cartes X sont un aperçu + **Open on X** — pas de like/repost/comment depuis PrideVault.
